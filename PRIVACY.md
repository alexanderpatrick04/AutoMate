# Privacy Policy

AutoMate does not collect, store, or transmit personal user data.

Vehicle listing information is processed locally within the user's browser in order to display vehicle insights such as:

* VIN decoding
* safety ratings
* recall information
* vehicle condition

AutoMate does not:

* track browsing history
* collect account credentials
* sell user data
* store personal information

Third-party APIs used:

* National Highway Traffic Safety Administration (NHTSA)

If you have questions regarding this privacy policy, please contact us through our GitHub repository.
